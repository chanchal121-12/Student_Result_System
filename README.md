# 🎓 Student Result System (C++)

This is a simple C++ project that calculates student marks and displays result.

---

## ✨ Features:
- Input student details (Name, Roll No)
- Enter marks of 3 subjects
- Calculate total marks
- Calculate percentage
- Display PASS / FAIL result

---

## 🛠️ Language Used:
- C++

---

## 🚀 How to Run:
- Open VS Code
- Compile using g++ compiler
- Run the program
